# BATPAPO — Multi-página (sem hash)

Cada tela é um arquivo HTML. A navegação usa páginas reais, não `#rota`.

## Páginas

| Arquivo | Tela |
|---------|------|
| `index.html` | Landing |
| `login.html` | Login |
| `register.html` | Cadastro |
| `home.html` | Início |
| `messages.html` | Mensagens / chat |
| `friends.html` | Amigos |
| `groups.html` | Grupos |
| `profile.html` | Laboratório do perfil |
| `stickers.html` | Sticker Studio |
| `notifications.html` | Notificações |
| `settings.html` | Configurações |
